# DLSS 5 Swapper 中文增强版

全界面与游戏内叠加层完整汉化，并修复部分游戏自带 D3D12 运行时被误判冲突导致无法安装的问题

## 这是什么

基于开源项目 [DLSS 5 Swapper](https://github.com/rakanki911/DLSS5-Swapper) 2.2.7 的中文增强版，为 NVIDIA DLSS 5（神经渲染）提供游戏/模拟器的一键安装与管理。

## 相比原版

- **完整中文汉化**：主界面 + 游戏内叠加层全量翻译
- **Bug 修复**：修复部分游戏（如 CoD 等）自带 Win7 D3D12 运行时被误判为冲突、导致无法安装的问题

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/41956418-cb59-4a4a-b938-bc864b182587" />

## 版本号说明

为方便大家理解，本次新版本号定为 1.0.1。版本号分两部分：整数位跟随原作者版本，原作者发布新版时递增（2.0.1、3.0.1…）；小数位为中文增强版的更新序号，仅中文增强版更新、原作者未更新时才会改动（1.0.2、1.0.3…）。

## 安装

无需任何环境依赖，下载 [Release](https://github.com/hezhixin15/DLSS5-Swapper-zh_CN/releases) 中的安装包，双击安装后即可使用。

部分游戏的渲染 API 会出现识别错误。如果你不知道如何查看自己游戏对应的 API，可以去下载一个“微星小飞机”APP。如果不会操作，可以去抖音或者哔哩哔哩上学习。

推荐安装这个中文增强版的时候，先把原版卸载掉，然后再安装这个。

## 這是什麼

基於開源專案 [DLSS 5 Swapper](https://github.com/rakanki911/DLSS5-Swapper) 2.2.7 的中文增強版，為 NVIDIA DLSS 5（神經渲染）提供遊戲／模擬器的一鍵安裝與管理。

## 相比原版

## 版本號說明
